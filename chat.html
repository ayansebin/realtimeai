Use it in your own Claudea skill that runs TTM r3 on your files, inside Claude
  1. Download the skill (ZIP, 23 MB, Apache 2.0)
  2. In Claude, open Customize, then Skills, and upload the ZIP. Code execution must be on.
  3. Drop in a CSV, Excel or JSON file and ask for a forecast or the anomalies.

Claude runs the models in its own sandbox and gives back a chart, the backtest and the Flink SQL to run the same models on Confluent Cloud. Team and Enterprise admins can add it for the whole org.
